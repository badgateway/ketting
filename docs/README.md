Ketting documentation
=====================

Ketting is a generic hypermedia client for JavaScript. It works in browsers
and in Node.js.

These pages are plain Markdown files that live next to the source code, so
they are versioned and reviewed together with it. The documentation for a
given release is the `docs/` folder of that release's git tag.
